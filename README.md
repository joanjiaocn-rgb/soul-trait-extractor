# Soul Color Test

A browser-based soul color quiz for symbolic self-reflection.

Soul Color Test turns everyday choices into a primary color, a supporting
shade, and a practical reflection about strengths, growth, relationships, and
work patterns.

- Live site: https://soulcolortest.online
- Source code: https://github.com/joanjiaocn-rgb/soul-trait-extractor

## What it does

Soul Color Test has two quiz modes:

- Quick Test: 7 questions, usually about 2 minutes
- Deep Test: 16 questions, usually about 5-6 minutes

The result maps answers across four reflective dimensions:

- Depth
- Clarity
- Connection
- Momentum

The highest dimension determines the primary color. The next highest dimension
becomes the supporting shade.

The four colors are:

- Gold: curiosity and exploration
- Blue: integrity and clarity
- Green: kindness and connection
- Red: determination and momentum

## Result includes

A completed result can include:

- Primary soul color
- Supporting shade
- Four signal scores
- Core strength
- Growth edge
- Relationship style
- Work and purpose signals
- Five-day alignment plan
- Shareable result card
- Individual color meaning page

See a complete example at:

https://soulcolortest.online/sample-report

## Privacy approach

Quiz scoring runs locally in the browser.

- Answers are not sent to a report-generation API.
- Quiz progress is stored locally in the browser.
- The site currently has no account system or checkout.
- Results are generated in the browser.
- Analytics may receive page views and interaction events.
- Do not enter sensitive personal information.

This project is designed for entertainment and self-reflection. It is not a
medical, mental health, hiring, scientific, or diagnostic assessment.
